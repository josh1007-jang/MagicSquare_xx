| | 내용 |
|---|------|
| **Role** | 4×4 부분 마방진 실습 학습자 — 빈칸 2개를 채우고 목표 합 34를 손·코드로 검증한다. |
| **Goal** | 행 4개·열 4개·대각선 2개 **총 10개 항목**을 모두 확인했을 때만 완성으로 판정하고, 하나라도 34가 아니면 **어느 항목**인지 즉시 알 수 있다. |

| **Output** | 10개 항목별 합 + pass/fail + 실패 시 해당 행/열/대각선 식별 |

## Rule — 검증 체크리스트

1. 검증 대상은 **행 4개, 열 4개, 대각선 2개** — 총 **10항목**이다.
2. 각 항목의 합이 **34**이어야 pass이다.
3. **10항목 중 하나라도 누락**되면 "완성" 판정을 내릴 수 없다.
4. fail 시 **실패한 항목명**(행 N / 열 N / 대각선 main|anti)을 보고한다.
5. 행·열만 확인한 부분 검증으로는 완성 판정을 금지한다.

### 검증 항목 정의

| ID | 항목 | 범위 |
|----|------|------|
| R1–R4 | 행 1–4 | `grid[row][0..3]` |
| C1–C4 | 열 1–4 | `grid[0..3][col]` |
| D1 | 주대각선 (main) | `grid[i][i]` for i=0..3 |
| D2 | 반대각선 (anti) | `grid[i][3-i]` for i=0..3 |

## Command — `/verify-magic-square`

**트리거:** 4×4 격자 입력 → 10항목 검증 실행

### 입력 형식

```
4×4 정수 배열 (0 = 빈칸)
목표 합: 34 (기본값)
```

### 출력 형식

```
각 항목: { id, sum, pass|fail }
전체: pass (10/10) | fail (N/10) + 실패 항목 목록
```

### 동작

1. 입력 격자 유효성 확인 (4×4, 값 0–16)
2. Rule에 따라 10항목 합 계산
3. 목표 합(34)과 비교
4. 결과 보고 (pass/fail + 실패 항목 식별)

## Test Loop

| TC | 시나리오 | 기대 결과 |
|----|----------|-----------|
| **TC1** | 모든 행·열·대각선 합 = 34 | pass (10/10) |
| **TC2** | 행·열 OK, 대각선 1개 fail (인터뷰 재현: 빈칸 2개 채운 뒤 대각선 하나 누락 검증) | fail + 실패 대각선(D1 또는 D2) 식별 |
| **TC3** | 대각선 검증 생략 (행·열만 8항목 실행) | Rule 위반 감지 — "완성" 판정 금지 |

|----|-----------|
