# STEP 3 — Report 폴더 내보내기

Report 폴더에 **세션 3 워크북 보고서**를 내보내줘.

## 입력

- `Report/MomTest_STEP1_MagicSquare_xx.md` (Mom Test 결과)
- 채워진 세션 3 워크북 (또는 `Prompting/STEP3_workbook_template.md` 기준 작성본)

## 보고서에 포함할 내용

- Mom Test 결과 요약 (페르소나, 진짜 문제, 증거 3줄)
- 주제 한 문장
- R-G-I-O
- 성공 기준 3개 (증거 연결)
- 표면 문제 — 하지 않을 것
- 8계층 (Rule, Command, Skill, Test Loop)
- 다음 세션 힌트

## 출력 파일

`Report/Session3_Workbook_MagicSquare_xx.md`

## 파일명 규칙

| 단계 | Report 파일 |
|------|-------------|
| STEP 1 Mom Test | `Report/MomTest_STEP1_MagicSquare_xx.md` |
| STEP 1 질문 뱅크 | `Report/MomTest_STEP1_Questions_MagicSquare_xx.md` |
| 세션 3 워크북 | `Report/Session3_Workbook_MagicSquare_xx.md` |
