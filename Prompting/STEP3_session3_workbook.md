# STEP 3 — MagicSquare_xx 세션 3 워크북

MagicSquare_xx **세션 3** 워크북을 채워.

## 입력 (Mom Test STEP 1 결과)

`Report/MomTest_STEP1_MagicSquare_xx.md` 를 읽고 아래를 사용:

- **페르소나:** 4×4 부분 마방진을 손으로/코드로 다루는 학습자
- **진짜 문제 (한 문장):** 확인 항목 하나를 빼먹어 틀린 상태로 20분을 쓴 뒤에야 잘못을 알 수 있다
- **Mom Test 증거 3줄:** 인터뷰ee 발언 인용 3줄

## 작성 항목

1. **주제 한 문장** — Mom Test 기반, 솔루션 최소화 (앱·프로그램·솔버 이름 금지)
2. **R-G-I-O** — Role / Goal / Input / Output
3. **성공 기준 3개** — Mom Test 증거와 각각 연결
4. **표면 문제** — 이번 프로젝트에서 **하지 않을 것** (Mom Test 표면 문제 재활용)
5. **8계층** — 이번 세션에서 만드는 것만: **Rule, Command, (Skill), Test Loop**

## 작성 원칙

| 항목 | 원칙 |
|------|------|
| 주제 | 불편·비용·판정·재현 중심, 솔루션 이름 없음 |
| R-G-I-O | 4×4 부분 마방진, 빈칸 2개, 합 34, 행·열·대각선 10항목 |
| 성공 기준 | 증거 ①②③ 각각과 1:1 매핑 |
| 표면 문제 | "~~프로그램/앱/솔버" 류 — 범위 밖 명시 |
| 8계층 | Rule·Command·Test Loop는 구체적; Skill은 선택 |

## 출력

완성 워크북 전체를 마크다운으로 출력한 뒤 `Report/Session3_Workbook_MagicSquare_xx.md` 에 저장.
